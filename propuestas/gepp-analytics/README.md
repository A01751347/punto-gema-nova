# One pager · Social analytics para GEPP

Comparativa en una hoja carta horizontal: el tablero actual de Open English contra la
plataforma propuesta para GEPP.

```bash
npm install
PAGE=landscape npm run build   # onepager.pdf + preview/p01.png
```

El build imprime la holgura entre el contenido y el pie; en una sola hoja debe quedar
en positivo. Si se agrega contenido, se recorta texto — no se baja el tipo.
